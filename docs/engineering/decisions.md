# Decisions

Every decision still in force that shapes the code, with its reason. Read this before changing
something that looks arbitrary: it probably is not.

- **Owner** marks a decision the repository owner made or confirmed, with its date. Do not reverse
  one without asking.
- **Taken** marks a choice made while building that the owner has not been asked to confirm. It
  stands until someone has a reason to reopen it; say so in review rather than changing it
  silently.
- **Design** marks a decision of the SOLAR design team, relayed by the owner.

A decision about one component is also written as the `reason` of its rule in
`spec/overlay/<name>.yaml`; that file is the authority for it, and this page only lists the
decisions a reader could not find there. When a decision is made or changed, update this page in
the same change.

## Process and repository

| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------- |

## Pipeline and generator

| Decision                                                                                                                                                                                                                                    | Status            |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------- |
| One normalizer, one spec, independent emitters; no target is transpiled from another. Agreement is proved by parity suites against the spec, so a conversion bug in one target fails the build.                                             | Owner 2026-09-21  |
| Components are generated for MUI and Flutter only; CSS and Tailwind get tokens.                                                                                                                                                             | Owner 2026-09-21  |
| The variables (`figma-variables.json`) win over Figma's prose, the page-context blocks and SOLAR Web. Conflicts are logged in `docs/solar/source-discrepancies.md`.                                                                         | Owner             |
| Findings are never averaged: geometry follows size, paint follows appearance and state, and every disagreeing variant is recorded. Where Figma's description and its variants disagree, the variants win; both are kept in the IR's `docs`. | Owner 2026-09-22  |
| Shared defaults hold only the zero insets: an unbound 0 padding is `inset.none`, an unbound 0 gap the none of its direction (`inset.none` across, `stack.none` down). Every other decision is the component's.                              | Owner 2026-09-24  |
| Sibling copies Figma draws as sample content are read as their first only by an opt-in `repeats` rule, never automatically: siblings meant to be distinct look the same to a rule that guesses.                                             | Owner 2026-09-25  |
| A composed child is a slot the caller fills, unless the parent cannot look like SOLAR without it (Button's Spinner, Tag's StatusIndicator, a group's buttons); those are generated components the parent composes.                          | Owner 2026-09-23  |
| Anything whose order reaches a generated file sorts by code unit (`byCodeUnit`, `src/util/sort.mjs`), never `localeCompare`, whose ICU order differs between Node builds.                                                                   | Taken             |
| Text decoration and case (the underline of `link/*`) come from `docs/solar/raw/text-styles.json`, fetched over REST, since the variable capture lacks them; one mapping, `src/emit/text-features.mjs`, feeds every target.                  | Owner 2026-09-23  |
| Components left out of the flow are named in `spec/overlay/excluded.yaml`: Cursor, the canvas editors' pointer glyphs, which are not built from Figma.                                                                                      | Owner 2026-09-24  |
| Patterns and views are not generated; components with no description (all on unused view pages) are not a concern.                                                                                                                          | Design 2026-09-24 |
| State values outside the platform ladder (`edit`, `today`, `other-month`, `today-column`, `no-results`, `search`, `rename`) stay SOLAR's; each becomes a boolean prop.                                                                      | Design 2026-09-24 |

## Tokens and icons

| Decision                                                                                                                                                                                                                                                                                                                                                                | Status           |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------- |
| Dark is `[data-theme='dark']` with no `:root` prefix, so a dark panel can sit in a light page. The MUI theme uses the same attribute in MUI's CSS-variables mode, so stock MUI and SOLAR components switch together; its palette values stay literal per scheme, since MUI derives channels and shades from them.                                                       | Owner 2026-09-25 |
| The Mobile type switch is derived from `viewport.sm` (`max-width: 767.98px`), never written by hand; CSS, MUI and Flutter switch at the same width.                                                                                                                                                                                                                     | Taken            |
| Alpha is quantized to 8 bits on every target, since Dart's `Color` has one byte for it. MUI letter spacing is `em`, so it stays right when the Mobile scale changes the size.                                                                                                                                                                                           | Taken            |
| Easing keywords are emitted as cubic béziers (Flutter has no keywords). `motion.ease.both` is emitted as ease-in-out and reported, since `ease-both` is not CSS.                                                                                                                                                                                                        | Taken            |
| A Dart identifier that is illegal or reserved is escaped with `$` (`$2xs`, `$default`), keeping SOLAR's spelling. `SolarTheme`'s type field is `typeScale`, since `ThemeExtension` declares `type`.                                                                                                                                                                     | Taken            |
| `color.border.inverse` is both a value and a group: it keeps both and is reported, not renamed to `.default`, which would invent a token.                                                                                                                                                                                                                               | Taken            |
| Tailwind gets the semantic layer, plus `motion.*` and the font families, which have none; font weights are left to Tailwind's own scale; Tailwind 4 only.                                                                                                                                                                                                               | Owner 2026-09-23 |
| App code writes SOLAR through the MUI theme, as workplace-web writes its V1 theme today (`sx` 790 uses, `theme.palette` 328, `Typography variant` 570; no CSS variables): SOLAR's 287 semantic colours in `theme.palette` under SOLAR's own structure (`sx={{ bgcolor: 'surface.raised' }}`), and its 47 text styles as `Typography` variants. Primitives are left out. | Owner 2026-09-26 |
| Names in the MUI theme are SOLAR's in camelCase, segment by segment for a palette path (`subtleAlpha`) and whole for a variant (`titleSm`): MUI's convention, and the words `solar_flutter` already uses. A colour that is also a group is its group's `main` (`border.inverse.main`).                                                                                  | Owner 2026-09-26 |
| A variant's default element follows MUI's own heading mapping (`titleLg` and `h4` are one style on an `h4`; `titleSm` an `h6`).                                                                                                                                                                                                                                         | Taken            |
| The MUI theme runs native colour mode, so `theme.alpha()` works on SOLAR's colours (in MUI's default mode it reads a channel variable MUI defines only for its own). SOLAR's translucent tokens first; relative colours need a browser from about 2024.                                                                                                                 | Owner 2026-09-26 |
| MUI's spacing unit stays 4 (`inset.2xs`), not narrowed to SOLAR's steps: MUI's own components call `theme.spacing(0.5)`.                                                                                                                                                                                                                                                | Taken            |
| The MUI theme's types live in `@bwp-web/components` (`solar-theme.generated.ts`), which peers MUI; `@bwp-web/styles` imports nothing from MUI.                                                                                                                                                                                                                          | Taken            |
| Flutter app code reaches the theme by `SolarTheme.of(context)` and `context.solar`, the widgets' fallback where none is installed; text styles carry no colour.                                                                                                                                                                                                         | Owner 2026-09-26 |
| Fonts are Fontsource static packages (Inter, Montserrat, IBM Plex Mono) and bundled TTFs in Flutter. Gotham is never shipped: it is commercial and the repository is public.                                                                                                                                                                                            | Owner 2026-09-23 |
| An icon never carries a colour; a logo always carries its own and its types refuse a tint.                                                                                                                                                                                                                                                                              | Owner            |
| Flutter omits the Teams mark (12 gradient fills): redrawing it is disproportionate, and flattening it would invent a brand colour. Any other skipped asset fails the build.                                                                                                                                                                                             | Taken            |
| Flutter draws icons from path strings with a hand-written parser (`svg_path.dart`), which accepts exactly the commands the JS parser accepts (`MLCHVZ`), so `solar_flutter` has no SVG dependency.                                                                                                                                                                      | Taken            |

## The two libraries

The contract is [architecture.md, Two libraries, one contract](architecture.md#two-libraries-one-contract).

| Decision                                                                                                                                                                                                                                                                                                       | Status           |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------- |
| Each library matches Figma on its own; the two share the IR and the rendering model, not API spellings or mechanisms. Parity checks reachability through each descriptor's `api` table.                                                                                                                        | Owner 2026-09-25 |
| Shells are hand-written files, TSX by a React engineer and Dart by a Flutter engineer; only stories are generated. A descriptor with `templates` or `owned` is refused.                                                                                                                                        | Owner 2026-09-25 |
| Names: SOLAR's word where SOLAR's description names the thing (`helper`, `mandatory`, a Button's `prio`, Button Group's `type`), otherwise MUI's on the web and Flutter's in Flutter.                                                                                                                          | Owner 2026-09-25 |
| Figma's `style` (Alert, Alert Small, Spinner, the calendar parts) is `variant` in code on both platforms, since React reserves `style`; the design review asks Figma to rename it.                                                                                                                             | Owner 2026-09-25 |
| `loading` stays a prop on both platforms: SOLAR draws it as a state (a Spinner, the label hidden but keeping its room). A control both disabled and loading is disabled.                                                                                                                                       | Owner 2026-09-25 |
| The Storybook deploys on the existing Vercel project with its settings unchanged, as V1's does: `packages/storybook` on this branch is a package that builds the components' Storybook into `dist/`. `main` stays production (V1); V2 is the `v2-SOLAR` branch deployment. Widgetbook is not deployed for now. | Owner 2026-09-26 |
| MUI 9 stays the peer dependency of `@bwp-web/components`.                                                                                                                                                                                                                                                      | Owner 2026-09-25 |
| `SolarProvider` is the one-line setup; a SOLAR component reads its props through the MUI theme (`useSolarProps`), as stock MUI components do.                                                                                                                                                                  | Owner 2026-09-25 |
| In Flutter a pressable is disabled by a null `onPressed` or `onChanged`, with a `disabled` getter and no parameter; a field takes `enabled`. Cards, Tab Item, Breadcrumb Item and Counter keep a `disabled` parameter, since disabled is a look of their own there, not the absence of an action.              | Owner 2026-09-25 |
| A Flutter widget keeps Figma's size on every axis Figma does not fill, even when a parent would stretch it (those built on Flutter's buttons too), and sits at the start of any extra room.                                                                                                                    | Owner 2026-09-25 |
| Every control has an invisible 44 × 44 target (`size.target.min`) that takes no room, since SOLAR's descriptions say the WCAG hit area is padded in code. Touching rows (menus, day cells, section nav, pagination items at 24) get no padded target where targets would overlap.                              | Owner 2026-09-24 |
| No Mobile type pass in the visual checks: every recipe reads type through `var(--solar-type-*)`, which one media query reassigns, and the token parity suite covers Mobile.                                                                                                                                    | Taken            |
