## Component set: Button

Triggers an action — submits forms, confirms decisions, performs commands. Not for navigation (use Link), toggling (use Switch), or selecting options (use Checkbox/Radio).

Variants (108):
• size — sm (36px) | md (44px, default) | lg (48px)
• prio — primary | secondary | tertiary
• state — default | hover | pressed | focus | loading | disabled
• danger — false | true (destructive/irreversible actions: delete, remove, revoke)

focus carries the shared effect style shadow/focus/default (shadow/focus/danger on danger buttons); loading swaps the label for a Spinner and blocks re-submission.

Sizing: sm renders below the 44px WCAG touch target — pad the hit area in code or reserve it for dense tables and toolbars. There is no xs or xl size; size=xl was renamed lg on 2026-09-23.

Labels: write as actions — “Save changes” not “OK”, “Delete project” not “Yes”. 1–3 words. Leading icon reinforces; trailing icon indicates direction; icon-only requires aria-label.

Rules: one primary per view. Danger is for destructive actions only — never for Cancel or Close. Never place two primary buttons side by side. Tertiary should not stand alone as the sole action.

## Documentation card

**Description**

Triggers an action. Use for submitting forms, confirming decisions, and performing commands. Not for navigation (use Link), toggling (use Switch), or selecting options (use Checkbox/Radio).

**Priority**

Primary The main action. One per view.  
Secondary Supporting actions alongside primary.  
Tertiary Optional or dismissible actions. Easy to skip.

**Danger**

Toggle danger on for destructive, irreversible actions — delete, remove, revoke.  
Works with any priority. Never use for Cancel or Close.

**Sizes**

xs (28px) Ultra-dense contexts: inline chips, row-level actions, toolbar clusters.  
sm (36px) Dense contexts: tables, toolbars. Pad to 44px hit area in code per WCAG.  
md (44px) Default. Forms, dialogs, page actions.  
lg (48px) High-emphasis: hero CTAs and marketing actions.

**Labels & Icons**

Write as actions: "Save changes" not "OK". "Delete project" not "Yes". 1–3 words. Be specific on danger buttons.  
Leading icon → reinforces action (trash + Delete)  
Trailing icon → indicates direction (arrow + Continue)  
Icon-only → always needs aria-label

**Rules**

- DO: One primary per view
- DO: Specific danger labels: "Delete project"
- DO: Secondary for Cancel alongside Primary for Submit
- DO: Tertiary for low-priority: "Learn more", "Skip"

- DON'T: Two primary buttons side by side
- DON'T: Danger styling on Cancel or Close
- DON'T: Disabled without explaining why
- DON'T: Tertiary as the only action — too easy to miss
