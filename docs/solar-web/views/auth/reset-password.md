## Documentation card

**Description**

The screen to set a new password from a reset link. Second half of the forgot-password flow; requires a valid token.

**Layout**

Auth card: title · new password + confirm fields · rules / strength meter · primary 'Reset password' · link-expiry note.

**Responsive**

Desktop centered card; mobile full-width stacked.

**States**

default, submitting, field errors (mismatch / weak), invalid or expired token (error + request-new), success → Sign In.

**Accessibility**

Labelled fields; strength + rules exposed to AT; errors via aria-describedby. Show/hide password. Announce an invalid token clearly.

**Rules**

State password rules + strength  
Require a confirm field  
Handle expired tokens gracefully  
Send to Sign In on success

Accept weak passwords silently  
Leave expired tokens unexplained  
Auto-submit  
Pre-fill the old password
