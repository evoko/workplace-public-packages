## Documentation card

**Description**

The screen for reviewing changes and publishing or deploying them to an environment. Summarises what will change, the target, and confirmation. For release actions.

**Anatomy**

Header · change summary / diff · target / environment selector · validation status · primary Publish / Deploy action · history link.

**Flow**

Review changes → pick target → resolve validation → confirm (Confirmation Dialog for irreversible / production) → progress + result.

**States**

ready, validating, blocked (errors), publishing (in progress), success, error. Primary action stays disabled until valid.

**Accessibility**

Announce validation and progress via aria-live. Destructive / production deploys require an explicit confirm. Keyboard-complete; visible focus; status not by colour alone.

**Rules**

Summarise changes before publish  
Show the target clearly  
Confirm irreversible deploys  
Report progress + result

Publish without a review step  
Hide the target environment  
Rely on colour for status  
Leave failures unexplained
