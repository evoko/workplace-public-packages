## Documentation card

**Description**

The org member directory — invite, view and manage people and their roles. Admin-only; users edit their own profile in User Profile.

**Layout**

Page header + Invite · Data Table (name · email · role · status) · Filter Panel / search · row actions (edit role · remove).

**Responsive**

Desktop: full table. Mobile: member cards / condensed rows.

**States**

loaded, loading, empty (invite prompt), no-results (filter), error; row states (pending invite, disabled).

**Accessibility**

Table with headers; row + bulk actions labelled and announced. Role change and remove confirmed. Keyboard-complete; visible focus.

**Rules**

Show role + status per member  
Confirm remove  
Support search + filter  
Handle pending invites

Let an admin remove themselves silently  
Hide status  
Bulk-act without confirm  
Expose others' private data
